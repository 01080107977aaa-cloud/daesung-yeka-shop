-- 대성농장 관리자 실제 DB 연동용 -- Supabase SQL Editor에서 1회 실행 -- 주의: 관리자 로그인 계정을 Supabase Authentication > Users에서 먼저 만든 뒤 -- 아래 YOUR_ADMIN_EMAIL을 실제 관리자 이메일로 바꾸고 실행하세요. create table if not exists public.admin_emails( email text primary key, created_at timestamptz not null default now() ); create or replace function public.is_admin() returns boolean language sql stable security definer set search_path=public as $$ select exists( select 1 from public.admin_emails a where lower(a.email)=lower(coalesce(auth.jwt()->>'email','')) ); $$; revoke all on function public.is_admin() from public; grant execute on function public.is_admin() to authenticated; -- ★ 여기 이메일을 실제 관리자 로그인 이메일로 변경 insert into public.admin_emails(email) values('YOUR_ADMIN_EMAIL') on conflict(email) do nothing; alter table public.products enable row level security; alter table public.orders enable row level security; alter table public.order_items enable row level security; alter table public.customers enable row level security; alter table public.order_events enable row level security; -- 고객 주문페이지는 로그인 없이 판매중 상품을 읽을 수 있어야 합니다. drop policy if exists customer_products_read on public.products; create policy customer_products_read on public.products for select to anon, authenticated using (is_active=true); drop policy if exists admin_products_all on public.products; create policy admin_products_all on public.products for all to authenticated using (public.is_admin()) with check (public.is_admin()); drop policy if exists admin_orders_select on public.orders; create policy admin_orders_select on public.orders for select to authenticated using (public.is_admin()); drop policy if exists admin_order_items_select on public.order_items; create policy admin_order_items_select on public.order_items for select to authenticated using (public.is_admin()); drop policy if exists admin_customers_select on public.customers; create policy admin_customers_select on public.customers for select to authenticated using (public.is_admin()); drop policy if exists admin_events_select on public.order_events; create policy admin_events_select on public.order_events for select to authenticated using (public.is_admin()); create or replace function public.admin_save_product( p_id uuid default null, p_name text default '', p_price numeric default 0, p_stock integer default 0, p_description text default '', p_image_url text default '', p_is_active boolean default true ) returns public.products language plpgsql security definer set search_path=public as $$ declare v public.products; begin if not public.is_admin() then raise exception '관리자 권한이 필요합니다.'; end if; if trim(coalesce(p_name,''))='' then raise exception '상품명을 입력해주세요.'; end if; if p_price < 0 or p_stock < 0 then raise exception '가격과 재고는 0 이상이어야 합니다.'; end if; if p_id is null then insert into public.products(name,price,stock,description,image_url,is_active) values(trim(p_name),p_price,p_stock,coalesce(p_description,''),nullif(trim(coalesce(p_image_url,'')),''),p_is_active) returning * into v; else update public.products set name=trim(p_name),price=p_price,stock=p_stock, description=coalesce(p_description,''),image_url=nullif(trim(coalesce(p_image_url,'')),''), is_active=p_is_active,updated_at=now() where id=p_id returning * into v; if not found then raise exception '상품을 찾을 수 없습니다.'; end if; end if; return v; end; $$; revoke all on function public.admin_save_product(uuid,text,numeric,integer,text,text,boolean) from public; grant execute on function public.admin_save_product(uuid,text,numeric,integer,text,text,boolean) to authenticated; -- 관리자 주문 목록: 고객정보 + 상품정보 + 정상상품금액(gross_amount)까지 반환 create or replace function public.admin_get_orders() returns jsonb language plpgsql security definer set search_path=public as $$ begin if not public.is_admin() then raise exception '관리자 권한이 필요합니다.'; end if; return coalesce((select jsonb_agg(x order by x.created_at desc) from ( select o.*, coalesce((select sum(oi.unit_price_snapshot*oi.quantity) from public.order_items oi where oi.order_id=o.id),0) as gross_amount, coalesce((select jsonb_agg(jsonb_build_object( 'product_id',oi.product_id, 'product_name',oi.product_name_snapshot, 'unit_price',oi.unit_price_snapshot, 'quantity',oi.quantity, 'amount',oi.amount ) order by oi.id) from public.order_items oi where oi.order_id=o.id),'[]'::jsonb) as items from public.orders o ) x),'[]'::jsonb); end; $$; revoke all on function public.admin_get_orders() from public; grant execute on function public.admin_get_orders() to authenticated; -- 관리자 주문 상태/송장 처리 create or replace function public.admin_order_action( p_order_id uuid, p_action text, p_tracking_number text default null, p_memo text default null, p_refund_amount numeric default null ) returns jsonb language plpgsql security definer set search_path=public as $$ declare o public.orders; begin if not public.is_admin() then raise exception '관리자 권한이 필요합니다.'; end if; select * into o from public.orders where id=p_order_id for update; if not found then raise exception '주문을 찾을 수 없습니다.'; end if; if p_action='입금확인' then update public.orders set payment_status='입금확인',shipping_status='상품준비',updated_at=now() where id=o.id; insert into public.order_events(order_id,event_type,message) values(o.id,'입금확인','관리자가 입금을 확인했습니다.'); elsif p_action='택배발송' then if nullif(trim(coalesce(p_tracking_number,'')),'') is null then raise exception '송장번호를 입력해주세요.'; end if; update public.orders set tracking_number=trim(p_tracking_number),shipping_status='배송중',updated_at=now() where id=o.id; insert into public.order_events(order_id,event_type,message) values(o.id,'택배발송','송장번호: '||trim(p_tracking_number)); elsif p_action='배송완료' then update public.orders set shipping_status='배송완료',updated_at=now() where id=o.id; insert into public.order_events(order_id,event_type,message) values(o.id,'배송완료','관리자가 배송완료 처리했습니다.'); elsif p_action='취소승인' then if o.cancel_status='정상' or o.cancel_status='취소요청' then update public.orders set cancel_status='취소완료', refund_amount=case when o.payment_status='입금확인' then coalesce(p_refund_amount,total_amount) else 0 end, payment_status=case when o.payment_status='입금확인' then '환불완료' else payment_status end, shipping_status='취소완료',updated_at=now() where id=o.id; update public.products p set stock=p.stock+oi.quantity,updated_at=now() from public.order_items oi where oi.order_id=o.id and oi.product_id=p.id; insert into public.order_events(order_id,event_type,message) values(o.id,'취소승인','관리자가 취소를 승인했습니다.'); end if; elsif p_action='취소거절' then update public.orders set cancel_status='정상',updated_at=now() where id=o.id; insert into public.order_events(order_id,event_type,message) values(o.id,'취소거절','관리자가 취소 요청을 거절했습니다.'); elsif p_action='메모' then insert into public.order_events(order_id,event_type,message) values(o.id,'메모',coalesce(p_memo,'')); else raise exception '지원하지 않는 작업입니다.'; end if; return jsonb_build_object('ok',true,'order_id',o.id); end; $$; revoke all on function public.admin_order_action(uuid,text,text,text,numeric) from public; grant execute on function public.admin_order_action(uuid,text,text,text,numeric) to authenticated; -- 관리자 주문자 정보 수정 create or replace function public.admin_update_order_customer( p_order_id uuid, p_buyer_name text, p_buyer_phone text, p_depositor_name text, p_address text, p_detail_address text default '', p_delivery_memo text default '' ) returns jsonb language plpgsql security definer set search_path=public as $$ begin if not public.is_admin() then raise exception '관리자 권한이 필요합니다.'; end if; update public.orders set buyer_name=trim(coalesce(p_buyer_name,'')), buyer_phone=trim(coalesce(p_buyer_phone,'')), depositor_name=trim(coalesce(p_depositor_name,'')), address=trim(coalesce(p_address,'')), detail_address=trim(coalesce(p_detail_address,'')), delivery_memo=trim(coalesce(p_delivery_memo,'')), updated_at=now() where id=p_order_id; if not found then raise exception '주문을 찾을 수 없습니다.'; end if; insert into public.order_events(order_id,event_type,message) values(p_order_id,'주문자수정','관리자가 주문자 정보를 수정했습니다.'); return jsonb_build_object('ok',true,'order_id',p_order_id); end; $$; revoke all on function public.admin_update_order_customer(uuid,text,text,text,text,text,text) from public; grant execute on function public.admin_update_order_customer(uuid,text,text,text,text,text,text) to authenticated; -- 관리자 상품/수량/금액 수정 create or replace function public.admin_update_order_items( p_order_id uuid, p_items jsonb, p_total_amount numeric ) returns jsonb language plpgsql security definer set search_path=public as $$ declare o public.orders; item jsonb; begin if not public.is_admin() then raise exception '관리자 권한이 필요합니다.'; end if; if p_total_amount < 0 then raise exception '총 금액은 0 이상이어야 합니다.'; end if; select * into o from public.orders where id=p_order_id for update; if not found then raise exception '주문을 찾을 수 없습니다.'; end if; if jsonb_typeof(p_items)<>'array' or jsonb_array_length(p_items)=0 then raise exception '상품 정보가 없습니다.'; end if; delete from public.order_items where order_id=o.id; for item in select * from jsonb_array_elements(p_items) loop insert into public.order_items(order_id,product_id,product_name_snapshot,unit_price_snapshot,quantity,amount) values(o.id,nullif(item->>'product_id','')::uuid,coalesce(item->>'product_name',''),coalesce((item->>'unit_price')::numeric,0),coalesce((item->>'quantity')::integer,1),coalesce((item->>'amount')::numeric,0)); end loop; update public.orders set total_amount=p_total_amount,updated_at=now() where id=o.id; insert into public.order_events(order_id,event_type,message) values(o.id,'주문수정','관리자가 상품/금액 정보를 수정했습니다.'); return jsonb_build_object('ok',true,'order_id',o.id); end; $$; revoke all on function public.admin_update_order_items(uuid,jsonb,numeric) from public; grant execute on function public.admin_update_order_items(uuid,jsonb,numeric) to authenticated; -- 관리자 고객 목록: 주문 DB를 기준으로 고객 정보를 구성해 스키마 차이를 최소화합니다. create or replace function public.admin_get_customers() returns jsonb language plpgsql security definer set search_path=public as $$ begin if not public.is_admin() then raise exception '관리자 권한이 필요합니다.'; end if; return coalesce((select jsonb_agg(x order by x.last_created_at desc) from ( with ranked as ( select o.*, row_number() over(partition by coalesce(o.customer_id,o.id) order by o.created_at desc) as rn from public.orders o where coalesce(o.cancel_status,'정상')='정상' ) select coalesce(r.customer_id,r.id) as id, split_part(coalesce(r.buyer_name,''),'||',1) as cafe_nickname, case when position('||' in coalesce(r.buyer_name,''))>0 then split_part(r.buyer_name,'||',2) else r.buyer_name end as name, r.buyer_phone as phone, trim(concat_ws(' ',r.address,r.detail_address)) as address, (select count(*) from public.orders o2 where coalesce(o2.customer_id,o2.id)=coalesce(r.customer_id,r.id) and coalesce(o2.cancel_status,'정상')='정상') as order_count, (select coalesce(sum(o2.total_amount),0) from public.orders o2 where coalesce(o2.customer_id,o2.id)=coalesce(r.customer_id,r.id) and coalesce(o2.cancel_status,'정상')='정상') as total_paid, r.created_at as last_created_at from ranked r where r.rn=1 ) x),'[]'::jsonb); end; $$; revoke all on function public.admin_get_customers() from public; grant execute on function public.admin_get_customers() to authenticated;
